# WOSHealth — documentación operativa

Auditoría y consolidación ejecutadas el 2026-11-10. Este repositorio contiene únicamente documentación técnica, inventarios no clínicos y decisiones de conservación.

## Estados

- `CURRENT`: observado en la ejecución remota o local indicada.
- `HISTORICAL`: evidencia anterior, no demostrada como activa.
- `UNKNOWN`: no verificable con el acceso disponible.
- `REVIEW_BLOCKED`: requiere credencial, decisión o evidencia adicional.

## Alcance

Incluye Módulo 1, Módulo 2 Capa 1, Módulo 2 Capa 2, Módulo 3, microbiología, alertas, automatizaciones, repositorios y limpieza. No incluye datos clínicos identificables, secretos ni correcciones funcionales.
